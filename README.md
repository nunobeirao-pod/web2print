# WEB2PRINT — Desktop + Studio (GitHub reset package)

This package replaces the full repository content with **only**:

- Design System (`Design System.dc.html`) + 8 Core Components (Button, Link, Input, Select, Checkbox, Radio, Badge, IconButton)
- Desktop pages: Homepage, Shop All (category listing), Tees, Hoodies and Sweats, Athleisure, Accessories, Product Page, Checkout, 404, Order Confirmation, Password Recovery, Search Results, Cookie Banner, Inspiration, For Teams, Who We Are, Dashboard, Authentication, Company, Talk to us

- Runtime dependencies: `support.js`, `image-slot.js`, `studio-data.js`
- `assets/` (Studio garment/mask images)

**Not included** (intentionally removed per this reset): Tablet and Mobile site pages, Mobile Navigation, Responsive Preview tools, documentation/handoff folders, previous ZIP exports.

Approved visual content of every included file is unmodified — only the file set was reduced.
