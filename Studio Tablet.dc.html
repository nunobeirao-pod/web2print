Tablet adaptation: this is not a new layout — it is Studio Desktop's own existing narrow mode (already coded as winW < 1180), which is well inside the 768–1023px Tablet range. Undo/Redo/Reset hide, Share/Save collapse to icon-only, the view switcher moves inline, and the inspector — already width:360px;max-width:100vw — becomes an absolute-positioned overlay toggled by the "Tools" icon instead of a permanently docked sidebar. Zoom and the Grid/Snap/Print area/Measurements toggles sit in a horizontally-scrolling strip, exactly as Desktop already does at this width — intentional internal scroll, not page overflow. Product, colours, text tool section (Bold/Italic/Underline, colour swatches, outline toggle) and the Add to Order footer are the same controls and copy as Studio Desktop; the full tool set (Shapes, Stickers, Layers, CMYK picker, etc.) is condensed here to the sections needed to demonstrate the responsive pattern, not redrawn or reinvented.
